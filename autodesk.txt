3. APP DESCRIPTION (4000 chars max)
───────────────────────────────────────────────────────────────────────────────
BIM Health Report is a cloud-based tool for AEC professionals to analyze Revit (.rvt) models and generate health reports using Autodesk Platform Services (APS) Design Automation.

REPORTS INCLUDE
• Element counts for walls, floors, doors, windows, rooms, and other categories
• Model completeness, geometric accuracy, information quality, and an overall A/B/C/D grade
• Revit warnings, errors, performance insights, worksets, design options, and linked files

HOW IT WORKS
1. Connect your Autodesk account in Settings.
2. Browse your Autodesk Forma hubs, projects, and folders to select a Revit model.
3. Select Process to analyze the model with Autodesk Design Automation.
4. View the report in the dashboard or download it as JSON. Reports are saved in your history.

AUTHENTICATION AND PERMISSIONS
The app uses both OAuth flows for different stages:
• 3-legged OAuth starts when a user connects Autodesk in Settings. The user's consented token is used to read that user's Autodesk Forma hubs, projects, folders, and files, subject to their Autodesk permissions. This is the only flow used to browse and select projects.
• The consent screen's Identity permission corresponds to user-profile:read (read the Autodesk profile); Data corresponds to data:read (read the user's project data). These are two permission categories within the same 3-legged flow, not separate authentication flows.
• 2-legged OAuth (client credentials) is used server-side after a Revit file is selected, to authenticate the app for Design Automation and temporary OSS input/output storage. It is not used to browse the user's projects. Its scopes are data:read, data:write, data:create, bucket:read, bucket:create, and code:all.

FEATURES AND REQUIREMENTS
• Automatic Revit version detection for Revit 2023–2027
• Interactive charts, sortable report data, JSON export, and report history
• Manual upload of Revit or BIM Health JSON files without Autodesk project browsing
• Requires an Autodesk account with access to the project and an APS app configured for the scopes above
• Includes a 7-day free trial; subscription plans are available in the app

Designed for BIM managers, architects, engineers, and project teams performing model quality checks before delivery.

9. GENERAL USAGE INSTRUCTIONS
───────────────────────────────────────────────────────────────────────────────
1. SIGN UP / SIGN IN
   Visit the app URL and register for a free 7-day trial (no credit card needed). Existing users can sign in directly.

2. ENTER AUTODESK CREDENTIALS
   Navigate to the ACC Browser page. Enter your APS Application Client ID and Client Secret. These are obtained from the Autodesk Platform Services portal (aps.autodesk.com). Click "Save Credentials."

3. LOG IN WITH AUTODESK
   Click "Login with Autodesk" to initiate the OAuth flow. You will be redirected to Autodesk's login page. After approving access, you are returned to the app.

4. BROWSE YOUR ACC PROJECTS
   Click "Load Hubs" to see your BIM 360/ACC hubs. Select a hub to load its projects. Select a project to browse its folder structure. Navigate folders to find your Revit (.rvt) files.

5. PROCESS A FILE
   Click the "Process" button next to any .rvt file. The app will submit the file to Autodesk Design Automation for analysis. Processing typically takes 1–5 minutes depending on model size and complexity.

6. VIEW YOUR REPORT
   Once processing completes, you are automatically redirected to the report page. The report displays element counts, quality metrics, issues, performance ratings, and an overall grade.

7. EXPORT & REVIEW
   Download the report as a JSON file for archiving or integration into your own tools. All reports are saved in your dashboard history for future reference.

ALTERNATIVE: MANUAL UPLOAD
   If you prefer not to use ACC integration, navigate to the Upload page and upload a .rvt file or an existing BIM Health JSON report directly.

11. ADDITIONAL INFORMATION (2000 chars max)
───────────────────────────────────────────────────────────────────────────────
TECHNICAL STACK
• Built with Next.js 14 (App Router) and TypeScript
• Autodesk Platform Services: Data Management API, Design Automation API, Model Derivative API
• Database: PostgreSQL via Prisma ORM
• Hosted on Vercel

APS PERMISSIONS REQUIRED
The app uses separate scopes for user-authorized ACC browsing and app-authorized processing:
   3-legged OAuth (user connects in Settings):
   user-profile:read  – Identity: read the Autodesk profile in the OAuth callback
   data:read          – Data: read the user's ACC hubs, projects, folders, and files

   2-legged OAuth (server-side Revit processing only):
      data:read, data:write, data:create – access and transfer temporary processing files
      bucket:create, bucket:read         – create/check the app's OSS bucket
      code:all                           – run Design Automation workitems

REVIT VERSION SUPPORT
The app automatically detects the Revit version of your file and runs it through the correct Design Automation engine. Supported versions: Revit 2023, 2024, 2025, 2026, 2027.

SUBSCRIPTION PLANS
• 7-Day Free Trial – Full feature access, no credit card required
• Paid Plans – Available after trial; manage via the Billing dashboard inside the app

DATA PRIVACY
Revit files are processed transiently via Autodesk Design Automation. Output reports are stored in your account only. No model geometry or proprietary data is retained on our servers beyond the report JSON.

KNOWN LIMITATIONS
• Processing time depends on Revit model complexity (typically 1–5 minutes)
• Very large models (>500 MB) may approach the processing time limit
• ACC file access requires 3-legged data:read permission. Revit cloud processing additionally requires the server-side 2-legged scopes listed above.


───────────────────────────────────────────────────────────────────────────────
12. KNOWN ISSUES (1000 chars max)
───────────────────────────────────────────────────────────────────────────────
• Large Revit files (over 500 MB) may occasionally time out during processing. If this occurs, try uploading the file manually via the Upload page instead.

• ACC file browsing requires the 3-legged "data:read" and "user-profile:read" scopes. Revit processing additionally uses a server-side 2-legged token with the OSS and Design Automation scopes listed above.

• Revit version auto-detection relies on the Autodesk Model Derivative manifest. For files that have not been previously translated, the app will attempt all supported versions (2023–2027) automatically.

• The app is hosted on Vercel's Hobby plan. Serverless function execution is limited to 300 seconds. Files requiring longer processing will return a timeout error.

HOW TO SETUP AUTODESK PLATFORM SERVICES (APS) APP
STEP-BY-STEP GUIDE FOR USERS
═══════════════════════════════════════════════════════════════════════════════

───────────────────────────────────────────────────────────────────────────────
STEP 1: CREATE AUTODESK PLATFORM SERVICES (APS) ACCOUNT
───────────────────────────────────────────────────────────────────────────────

1. Go to: https://aps.autodesk.com
2. Click "Sign In" (top right corner)
3. Use your Autodesk account (same as ACC/BIM 360 login)
4. If no account: Click "Create Account" and register


───────────────────────────────────────────────────────────────────────────────
STEP 2: CREATE A NEW APP
───────────────────────────────────────────────────────────────────────────────

1. After login, go to: https://aps.autodesk.com/myapps
2. Click "Create App" button
3. Fill in the form:
   
   App Name: BIM Health Report Client
   
   App Description: Personal app to access BIM Health Report tool
   
   App Type: Select "Web App"


───────────────────────────────────────────────────────────────────────────────
STEP 3: CONFIGURE CALLBACK URL (MOST IMPORTANT!)
───────────────────────────────────────────────────────────────────────────────

In the "Callback URL" field, enter EXACTLY:

   https://bim-health-report.vercel.app/auth/callback

⚠️ IMPORTANT: 
   - NO trailing slash (/)
   - HTTPS required (not http)
   - Must match exactly
   - If you're testing on localhost, use: http://localhost:3000/auth/callback


───────────────────────────────────────────────────────────────────────────────
STEP 4: SELECT APIs (ENABLE REQUIRED APIS)
───────────────────────────────────────────────────────────────────────────────

Check these APIs:

✅ Data Management API (REQUIRED)
✅ Model Derivative API (REQUIRED)
✅ Design Automation API (REQUIRED - for processing Revit files)
✅ Authentication (OAuth) - automatically enabled


───────────────────────────────────────────────────────────────────────────────
STEP 5: GET YOUR CREDENTIALS
───────────────────────────────────────────────────────────────────────────────

After creating the app:

1. You'll see:
   - Client ID (looks like: mmkSETAs4xPXHcGIYUu4pyvsGcNXt8eTcy66Vcydgr3OPRQ)
   - Client Secret (hidden with dots: •••••••••••••)

2. Click "Show" next to Client Secret to reveal it

3. COPY BOTH:
   - Client ID
   - Client Secret

⚠️ Keep Client Secret PRIVATE! Don't share publicly.


───────────────────────────────────────────────────────────────────────────────
STEP 6: USE CREDENTIALS IN BIM HEALTH REPORT APP
───────────────────────────────────────────────────────────────────────────────

1. Go to: https://bim-health-report.vercel.app/acc

2. In the "Autodesk Credentials" section:
   - Paste Client ID in first field
   - Paste Client Secret in second field

3. Click "Save Credentials"

4. Click "Login with Autodesk"

5. Autodesk login page will open → enter your Autodesk email/password

6. Click "Allow" to grant access

7. You'll be redirected back → now you can browse ACC projects!


───────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING COMMON ERRORS
───────────────────────────────────────────────────────────────────────────────

ERROR: "Request error" on Autodesk login page
FIX: 
   - Check Callback URL is EXACTLY: 
     https://bim-health-report.vercel.app/auth/callback
   - No extra spaces or characters
   - Must end with /auth/callback

ERROR: "Authentication failed"
FIX:
   - Verify Client ID and Client Secret are correct
   - Copy-paste again (avoid typing manually)
   - Check for extra spaces

ERROR: "Missing authorization header" when loading hubs
FIX:
   - Click "Login with Autodesk" first
   - Complete the OAuth flow
   - Then click "Load Hubs"

ERROR: "ACC File Processing Not Available"
FIX:
   - Your app doesn't have BIM 360/ACC API permissions
   - Solution: Use "Manual Upload" instead (Upload page)
   - OR: Contact Autodesk Support to request BIM 360/ACC API access
